# Event Pocket

> Collect signals. Build insights.

面向展会、发布会、论坛等活动的浏览器证据采集插件。把浏览网页时发现的**原文**和你的**批注**保存下来，按项目分级管理，最后统一导出一个研究素材包，直接交给洞察 Skill 使用。

## 它解决什么问题

做展会洞察时，信息是在浏览网页时零散发现的，但分析在另一个工作流里完成。过去需要手动复制几十个链接并重新解释"为什么重要"，Event Pocket 把这一步结构化。

```text
浏览网页 → 选中原文 → 加批注 → 保存
→ 持续累积多条 → 按项目/主题/类目整理 → 统一导出一个素材包
```

## 核心能力

- **原文 + 批注**：原文摘录为必填，批注为选填；同时自动记录网页标题、URL、来源、发布时间、采集时间。
- **分级分类**：项目 → 主题 → 类目的可视化三级树；每个项目节点可直接新增主题，每个主题节点可直接新增类目。
- **查看全部 / 未归类**：侧栏「项目」下两个跨项目入口，可直接看到没归入任何项目的素材并就地归档。
- **多条累积，统一导出**：不会每保存一次就生成一个文件。
- **筛选与搜索**：按项目、主题、类目和关键词快速定位素材。
- **导出 Markdown / JSON**：按层级生成，可直接喂给洞察 Skill。
- **导入 JSON**：便于备份和迁移。
- **换肤**：管理页「换肤」按钮可切换 5 套配色，默认「深红」；划词浮窗与管理页同步换色。
- **无状态流转**：不再为素材设置“未整理 / 已确认”等状态，素材只按归属、内容与标签管理。

## 换肤

管理页顶部「换肤」→ 选择一套 → 立即生效并记住选择。可选配色：

| 主题 | 主色 | 说明 |
|---|---|---|
| 深红（默认） | `#B9182A` | 白底深红，红只留给主操作 |
| 静蓝 | `#35618F` | 冷白蓝底，红只点引用线与警示 |
| 焰红 | `#CE2C26` | 暖白底 + 焰红，红全留给动作 |
| 品红 | `#B93B78` | 品红管动作，薄荷绿 `#1F9E86` 管引用与标签 |
| 紫辉 | `#5B45A8` | 初号机紫为主，橙 `#D98324` 与绿 `#4A9E4F` 只做点缀 |

每套主题带一个 `en` 英文小词（crimson / rei / asuka / mari / shinji），显示在换肤卡片名称旁的小字里。EVA 四套共用 danger 色 `#B8324A`，与各自的 accent / hot 拉开距离，删除操作不会被误读成「重点」。

主题变量写在 `document.documentElement` 上（弹窗在 `.ep-app` 之外，只有 `:root` 级别变量才全局生效）；浮窗在 Shadow DOM 内，通过后台 `EP_GET_TREE` 读同一设置后写 `data-theme`。新增主题需同时改 `src/themes.js` 与 `src/content.css`。

## 安装（Chrome 开发者模式）

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录 `event-pocket`

## 使用方式

### 方式一：划词即采集（推荐）

在任意网页选中一段文字 → 附近自动出现「● 收进 Event Pocket」气泡 → 点开填写批注（可留空）、**顺手选好归档位置** → 保存。浮窗标题栏可拖动；项目、主题、类目旁的「+ 新增」可直接创建并立即选中。

采集卡片里的层级与管理页完全同步：

```text
项目          ← 一级，下拉列出管理页已有项目
  主题 类目   ← 二级，缩进显示，只列出当前项目下的主题，类目再跟随主题
```

- 项目默认选中上次用过的那个；
- 切换项目时，主题、类目自动重置为该项目的二级列表；
- 保存后提示条会显示归档路径，例如「IFA 2026 / AI 与主动执行」；
- 不选则落入「未归类」，可在管理页再编辑（见下方「查看全部 / 未归类」）。

### 查看全部 / 未归类

侧栏「项目」区块顶部有两个跨项目入口，各带条数：

| 入口 | 显示范围 |
|---|---|
| 查看全部 | 所有素材，已归类和未归类一起看 |
| 未归类 | 只显示还没归入任何项目的素材 |

在这两个视图下：

- 卡片会多显示所属项目（未归类的打「未归类」标记），一眼能分辨归属；
- 主题 / 类目列表展开为**所有项目**的主题，点主题可按主题跨项目筛选；
- 直接点卡片「编辑」即可归档——项目下拉切换后，主题、类目会跟着重算；
- 导出时文件名与 Markdown 标题会标明「全部素材」或「未归类素材」。

当前视图会记在 `settings.viewMode` 里，重开侧栏后保持。

原文已自动填入，你只需要写一句"为什么值得留"。也可按 `Alt + Shift + S` 直接调出采集卡片。

### 方式二：右键菜单

普通网页：选中文字 → 右键 → 「收录到 Event Pocket」。原文直接入库，批注留空，之后可在管理页补充归档与批注。

**PDF Quick Collect**：Chrome 内置 PDF 阅读器不允许插件注入划词浮窗。打开 PDF 后，选中文字 → 右键 → 「收录到 Event Pocket」，插件会打开自己的 PDF 收录窗，并自动带入选文、PDF 文件名与原始 URL；可填写选填批注、选择或新增项目 / 主题 / 类目后收录。PDF 素材在管理页会带 `PDF` 标记。

### 方式三：手动补录

侧边栏或管理页点「新增素材」，手动粘贴原文和批注，适合补充线下看到的内容。

### 项目 / 主题 / 类目怎么编辑

左侧栏每个节点上都有操作按钮：

| 按钮 | 作用 |
|---|---|
| `+` | 新建（项目标题旁 / 主题行上是新建主题、主题行 `+` 是加类目） |
| `✎` | 重命名，弹窗预填当前名称 |
| `×` | 删除（项目会连带删除主题类目和素材，均有二次确认） |

素材要挪到别的主题/类目，点素材卡片的「编辑」，用里面的项目 → 主题 → 类目三级联动下拉改。

### 素材管理：点击图标即开侧边栏

- **左键点击图标** → 浏览器右侧直接打开素材管理侧边栏，边逛网页边归类，不占标签页；
- **右键点击图标** → 「在新窗口打开素材管理」，独立小窗口，适合需要更大空间整理；
- **网页右键菜单** → 「打开 Event Pocket 素材管理」同样是侧边栏。

采集全部交给划词浮窗，两条动作互不打断。不支持侧边栏的浏览器自动降级为独立小窗口 / 标签页。

侧边栏、小窗口、标签页内容完全相同，都是插件内置页面（`chrome-extension://`），**离线可用，不需要部署任何线上服务**。

> 改动后必须在 `chrome://extensions` 点击 Event Pocket 卡片的刷新图标才生效。

```text

```

## 浏览器兼容性

Chrome 与 Edge 同为 Chromium 内核，**共用同一份代码，不需要做两个版本**。扩展目录可以直接在 Edge 的 `edge://extensions` 里加载。

如果 Edge 上划词没有反应，按以下顺序排查：

1. **刷新目标网页**：content script 只在页面加载时注入，装完扩展或刷新扩展后必须刷新网页；
2. **检查站点访问**：`edge://extensions` → Event Pocket → 详情 → 「网站访问权限 / 站点访问」改为「在所有站点上」；
3. **确认扩展已启用**：列表里开关是打开的，且版本号为 0.2.0；
4. Edge 版本需 ≥ 114（侧边栏功能），划词采集本身不受此限制。

## 本地预览

不想先安装扩展时，直接打开：

```text
preview.html
```

预览版使用浏览器 localStorage，包含**划词浮窗演示**（在顶部文章里选中文字即可触发，用的就是插件真实的 `content.js`）、模拟采集面板和演示数据，可完整体验采集、分类和导出流程。

## 导出格式示例

```markdown
# IFA 2026 研究素材包

> Event Pocket · Collect signals. Build insights.

## AI 与主动执行

### 家庭场景

#### Source 001 · 官方回顾

- URL：https://...
- 来源：IFA 官方
- 类型：官方活动

**原文摘录**

> 设备开始主动协同完成任务。

**用户批注**

支持"主动执行、多端协同"趋势，需补第二来源。
```

## 边界

Event Pocket 只负责**采集、归档、批注、导出**。来源校验、优先级判断、趋势提炼由洞察 Skill 完成，页面编排和 PPT 生成由 PPT Skill 完成。插件不替用户判断哪些资料重要。
